# Candle Visualizer
This visualizer relies on TradingView's lightweight charting library, (inventively) named "Lightweight charts".
Using the `ohlcv.json` and `inds.json`, it visualizes the candles as well as all the indicators.

## Quickstart
Make sure to have `python`, `node` and `npm` installed.
```bash
$ npm install
$ python -m http.server 8080
```
Open `http://localhost:8080`.
